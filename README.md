
# Utafiti Sera Urban Governance House Repository  

A digital knowledge platform for **urban governance, social safeguards, and participatory planning**—designed to make research, policy, and community knowledge **discoverable, usable, and actionable**.

---

## About Utafiti Sera

**Utafiti Sera** (Research–Policy) bridges the gap between **evidence and decision-making** in urban development.  
This repository is part of that ecosystem—structuring knowledge into formats that policymakers, practitioners, and communities can engage with.

---

## What This Repository Does

- Centralizes urban governance knowledge
- Translates complex research into accessible formats
- Enables fast discovery through search and filters
- Surfaces community-led and practice-based evidence

---

## Core Features

- **Search** by keyword, title, or topic  
- **Category navigation** (e.g. Social Safeguards, Urban Planning)  
- **Content-type filtering** (policy briefs, case studies, interviews, etc.)  
- **Structured content cards** with metadata  
- **Responsive design** (mobile + desktop)  
- **Modal deep-dive views** for each resource
